# The Council — Named Tools and Capabilities

**What it is:** The roster of the workspace's standing tool personas — the named capability
clusters that own the methods, standards, and infrastructure documented in this export.

---

## What the Council is

Arcanum organizes its tooling as a **council of named personas**. Each name below is a stable,
public identifier for one capability cluster — archive recovery, document extraction, data
platforms, animation, and so on — never a person. The names are used consistently across the
documentation, so a framework doc can say "extraction infrastructure" and the roster can say
which standing capability owns it.

The roster currently counts **17 active members**. One earlier member is retired, with its
responsibilities formally transferred to a successor (recorded below, as succession is part of
the audit trail — capabilities are never silently renamed or absorbed).

## Notes

- The framework docs in [`docs/frameworks/`](frameworks/) describe the methods several of these
  capabilities maintain; this roster is the index of who owns what, not a tutorial.
- Roles are labels for auditability: a capability's one-liner is its current mandate, and changes
  to it are recorded rather than implied.
- Membership changes are always explicit — additions, retirements, and successions appear in this
  roster with their dates and evidence in the private layer; the public export carries the result.
